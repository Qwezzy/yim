# YIM website (2026 rebuild)

Static site for Yakha Ikusasa Manje. No Bootstrap. No jQuery. Header/footer injected by `js/main.js`.

## Brand
- Official logo only: the current **YIM wordmark with AIDS ribbons** (`images/YIM-LOGO.png`, also at https://www.yim.org.za/images/YIM-LOGO.png).
- Compact header version: `images/logo.png`.
- **Do not use** the old five-people circle lockup (the colourful figures around a black/white flower). That mark is retired and must not appear anywhere on the site.
- Palette: green `#2f9e3a`, gold `#f0c400`, blue `#1d4ed8`, red `#e11d2a`, ink `#161616`.

## Pages
`index.html` `about.html` `programmes.html` `impact.html` `gallery.html` `team.html` `events.html` `donate.html` `contact.html`

Content is drawn from the 2023 annual report and the 2024–2025 draft report (learner reach, HTS numbers, gardens, offices, board).

Photos try `assets/photos/` first, then fall back to images already in this repository.

## Donations
`donate.html` posts to PayFast. Edit `js/config.js` to leave sandbox and to add the real bank account.
