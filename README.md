# YIM website (2026 rebuild)

Static site for Yakha Ikusasa Manje. No Bootstrap. No jQuery. Header/footer injected by `js/main.js`.

## Brand
- Primary logo: `assets/logo.svg` (always loads; no binary required)
- Optional PNG: `assets/logo-light.png`, `assets/logo-dark.png`
- Palette: green `#2f9e3a`, gold `#f0c400`, blue `#1d4ed8`, red `#e11d2a`, ink `#161616`

## Pages
`index.html` `about.html` `programmes.html` `impact.html` `events.html` `donate.html` `contact.html`

Content is drawn from the 2023 annual report and the 2024-2025 draft report.
Photos try `assets/photos/` first, then fall back to images already in this repository.
